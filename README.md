Este é um CRUD completo feito com API em NODEJS e MYSQL, tentei criar uma API no level 2 o máximo o possível.

Para as próximas atualizações pretendo evoluir esta API para o Level 3

<h1>PARA USAR ESTE SOFTWARE!!!</h1>

***INSTALE ELE***

Aperte em "CODE" e depois descompacte ele

Abra o programa em um editor de código(Pode ser o vscode mesmo)

No terminal rode **npm i** - Você baixará todas as dependências

***PARA INCIAR***

Ainda no terminal digite "npm start" e seu software estará rodando

***PARA MANIPULAR***

Acesse o POSTMAN ou instale a extensão rest do vscode, neles você poderá acessar a API
